## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Start the local Vite development server:
```bash
npm run dev
```

3. Open the browser at:
```text
http://localhost:5173/
```

> **Note**: This project runs on **Vite** (port `5173` or `5174`), not on port `3000`.

## Build for Production

```bash
npm run build
```
